# Redmine Relation

Консольный инструмент на Python для создания связей между задачами в Redmine через REST API.

Проект разработан для упрощения внутренней работы с задачами: скрипт получает задачи, связанные с исходной задачей, и позволяет создавать связи между ними и другой выбранной задачей.

## Возможности

- Получение списка задач, связанных с исходной задачей.
- Получение названий и статусов связанных задач.
- Отображение прогресса обработки задач.
- Фильтрация по статусу: все задачи, открытые или закрытые.
- Создание связей типа `relates` с целевой задачей.
- Отображение результатов HTTP-запросов при создании связей.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/LoshkaSahara/redmine_relation.git
cd redmine_relation
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск

Скрипт можно запускать двумя способами: через готовый исполняемый файл `.exe` в Windows или непосредственно из исходного кода Python.

### Windows: запуск через EXE

Актуальные версии `.exe` можно найти на странице релизов - [releases](https://github.com/LoshkaSahara/redmine_relation/releases)

Также можно запустить его из PowerShell или командной строки:

```powershell
.\redmine_relation.exe
```

Если файл называется иначе, укажите его фактическое имя.

При первом запуске скрипт запросит адрес Redmine и API-ключ. Эти данные сохраняются в файле `settings.ini`.

При использовании готовой сборки устанавливать Python и зависимости отдельно не требуется, если они включены в сборку.

### Настройка подключения

При первом запуске укажите адрес Redmine и API-ключ. Они сохраняются в файле `settings.ini`.

Чтобы изменить настройки подключения, удалите `settings.ini` и запустите скрипт повторно.

## Использование

1. Укажите ID исходной задачи — скрипт получит список связанных с ней задач.
2. Укажите ID целевой задачи, с которой нужно создать новые связи.
3. Дождитесь обработки связанных задач и просмотра их статусов.
4. Выберите нужный вариант:
   - `1` — связать все найденные задачи.
   - `2` — связать открытые задачи.
   - `3` — связать закрытые задачи.
5. Проверьте результаты запросов в консоли.

В текущей версии проверка закрытого статуса основана на точном названии `Закрыт`. Если в вашем Redmine используются другие названия статусов или другой язык, логику определения статуса в `main.py` может потребоваться изменить.

## Безопасность

Файл `settings.ini` содержит адрес Redmine и API-ключ. Не публикуйте его и не добавляйте в Git-репозиторий.

Перед запуском проверьте ID исходной и целевой задач. Скрипт создаёт связи в Redmine, поэтому сначала рекомендуется проверить его работу на тестовом экземпляре или на задачах, предназначенных для проверки.
