# redmine_relation
Это скрипт для добавления связанных задач.  
Добавление происходит из задачи `A` в задачу `B`

Все данные пользователя (**адрес redmine** и **ключ API**) хранятся в файле `settings.ini`. Этот файл создаётся при первом запуске скрипта

Если необходимо изменить данные пользователя, то нужно удалить файл `settings.ini` и при следующем запуске скрипта указать новые данные
